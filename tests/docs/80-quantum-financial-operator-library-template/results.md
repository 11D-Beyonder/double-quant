- 算法库只登记 Func-1 至 Func-10 十类算法。
- 编程语言体系只分为“决策性问题”和“估值性问题”。
- 软件模板只覆盖动态账本更新算法、去中心化金融管理算法、反欺诈监测算法、支付与结算系统算法、贷款发放决策算法、银行网点布局优化算法、指数追踪算法。
- 内部问题实例工厂不作为算法展示，也不进入对外清单。
