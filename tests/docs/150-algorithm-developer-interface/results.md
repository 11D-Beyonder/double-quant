# 150 面向算法开发人员的编程开发接口测试结果

## 功能入口

- 前端访问地址：`https://janusq.zju.edu.cn/quantumFinance/QuantumCode`
- 页面名称：量子编程
- 覆盖功能点：面向算法开发人员的编程开发接口

## UI 操作流程

1. 打开 `/QuantumCode` 页面，确认顶部导航选中“量子编程”。
2. 查看左侧“量子门工具栏”，确认单比特门、多比特门、测量门可用于算法电路构建。
3. 在中间“电路可视化”区域选择 `20bit 投资组合选择` 模板，并点击“加载模板”。
4. 查看右侧 `OpenQASM` 代码编辑器，确认模板代码已载入。
5. 点击“运行”，等待电路可视化区域展示运行结果。
6. 查看“运行结果”中的测量次数、量子比特数、电路深度、最可能状态和测量结果分布。
7. 查看底部状态栏，确认量子比特和经典比特数量更新为 20。

## 页面输出

- 量子门工具栏支持算法开发人员通过拖拽量子门构建量子线路。
- 模板选择器支持加载金融算法相关 QASM 模板。
- OpenQASM 代码编辑器展示可编辑算法代码。
- 运行按钮能够触发量子线路运行。
- 运行结果区域展示测量次数、量子比特数、电路深度、最可能状态和测量结果分布。
- 状态栏展示当前线路的量子比特数和经典比特数。


## 验证结论

通过浏览器 UI 操作确认，量子编程 页面提供量子门工具栏、算法模板加载、OpenQASM 代码编辑、电路可视化、运行入口、运行结果和状态栏信息，满足“面向算法开发人员的编程开发接口”功能点要求。
