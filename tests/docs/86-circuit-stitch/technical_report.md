# 86 量子程序智能拼接技术测试（Func-53） 技术报告

## 技术设计

量子程序智能拼接模块的实现入口是 `double_quant.algorithm.circuit.stitch_circuits()`。该函数接收左侧电路 `left`、右侧电路 `right`，按照量子比特和经典比特映射规则，把 `right` 顺序拼接到 `left` 后面，输出新的 `StitchResult`。

输出对象包含：

| 字段 | 说明 |
|---|---|
| `circuit` | 拼接后的 Qiskit 电路 |
| `qubit_map` | 右侧电路量子比特索引到输出电路量子比特索引的映射 |
| `clbit_map` | 右侧电路 clbit 索引到输出电路 clbit 索引的映射 |
| `diagnostics` | 自动映射、显式映射、线宽扩展等记录 |

整体流程如下：

```text
输入左侧电路和右侧电路
  -> 规范化量子比特映射和经典比特映射
  -> 检查目标线宽是否足够
  -> allow_extend=True 时扩展输出电路寄存器
  -> 调用 QuantumCircuit.compose()
  -> 输出 StitchResult
```

### 1. 同线宽自动拼接

当两段电路线宽一致时，模块默认按索引自动映射。示例中左侧电路为 `H(q_0)`：

```text
左侧原始电路：
     ┌───┐
q_0: ┤ H ├
     └───┘
q_1: ─────
左侧摘要：量子比特数=2，经典比特数=0，门操作={'h': 1}
```

右侧电路为 `CX(q_0, q_1)`：

```text
右侧待拼接电路：
q_0: ──■──
     ┌─┴─┐
q_1: ┤ X ├
     └───┘
右侧摘要：量子比特数=2，经典比特数=0，门操作={'cx': 1}
```

拼接后电路为：

```text
拼接后电路：
     ┌───┐
q_0: ┤ H ├──■──
     └───┘┌─┴─┐
q_1: ─────┤ X ├
          └───┘
拼接后摘要：量子比特数=2，经典比特数=0，门操作={'h': 1, 'cx': 1}，量子比特映射={0: 0, 1: 1}，经典比特映射={}
```

该结果表示右侧电路第 0、1 个量子比特 分别映射到输出电路第 0、1 个量子比特。

### 2. 显式映射拼接

当用户需要改变右侧电路的接入位置时，可以传入显式映射。例如 `qubit_map={0: 1, 1: 0}` 表示：

```text
右侧 q[0] -> 输出 q[1]
右侧 q[1] -> 输出 q[0]
```

右侧待拼接电路仍然是 `CX(q_0, q_1)`：

```text
右侧待拼接电路：
          
q_0: ──■──
     ┌─┴─┐
q_1: ┤ X ├
     └───┘
右侧摘要：量子比特数=2，经典比特数=0，门操作={'cx': 1}
```

经过映射后，右侧控制位 `q[0]` 接入输出 `q_1`，右侧目标位 `q[1]` 接入输出 `q_0`。

拼接前左侧电路：

```text
左侧原始电路：
     ┌───┐
q_0: ┤ X ├
     └───┘
q_1: ─────
左侧摘要：量子比特数=2，经典比特数=0，门操作={'x': 1}
```

拼接后电路：

```text
拼接后电路：
     ┌───┐┌───┐
q_0: ┤ X ├┤ X ├
     └───┘└─┬─┘
q_1: ───────■──
拼接后摘要：量子比特数=2，经典比特数=0，门操作={'x': 1, 'cx': 1}，量子比特映射={0: 1, 1: 0}，经典比特映射={}
量子比特映射明细：右侧 q[0] -> 输出 q[1]，右侧 q[1] -> 输出 q[0]
```

图中 CNOT 的控制点位于 `q_1`，目标 X 位于 `q_0`，说明显式映射已经生效。

### 3. 自动扩展拼接

当右侧电路比左侧电路线宽更大时，默认不隐式扩展；用户必须设置 `allow_extend=True`。例如左侧只有 1 个量子比特：

```text
左侧原始电路：
   ┌───┐
q: ┤ H ├
   └───┘
左侧摘要：量子比特数=1，经典比特数=0，门操作={'h': 1}
```

右侧需要 2 个量子比特：

```text
右侧待拼接电路：
q_0: ──■──
     ┌─┴─┐
q_1: ┤ X ├
     └───┘
右侧摘要：量子比特数=2，经典比特数=0，门操作={'cx': 1}
```

启用扩展后，输出电路新增 `stitch_q` 寄存器：

```text
拼接后电路：
          ┌───┐
       q: ┤ H ├──■──
          └───┘┌─┴─┐
stitch_q: ─────┤ X ├
               └───┘
拼接后摘要：量子比特数=2，经典比特数=0，门操作={'h': 1, 'cx': 1}，量子比特映射={0: 0, 1: 1}，经典比特映射={}
```

该机制让拼接结果显式反映线宽变化，避免用户误以为右侧电路被截断或复用了错误 量子比特。

### 4. 不兼容线宽拦截

当 `left` 只有 1 个量子比特、`right` 有 2 个量子比特，并且未设置 `allow_extend=True` 时，模块抛出 `CircuitStitchingError`。测试中左侧不是空电路，而是包含一个 `H` 门：

```text
左侧原始电路：
   ┌───┐
q: ┤ H ├
   └───┘
左侧摘要：量子比特数=1，经典比特数=0，门操作={'h': 1}
```

右侧待拼接电路需要两个量子比特：

```text
右侧待拼接电路：
          
q_0: ──■──
     ┌─┴─┐
q_1: ┤ X ├
     └───┘
右侧摘要：量子比特数=2，经典比特数=0，门操作={'cx': 1}
```

由于调用参数为 `allow_extend=False`，模块不能自动把 1 线宽输出扩展成 2 线宽输出，因此拒绝拼接。测试输出为：

```text
拼接参数：allow_extend=False
拒绝原因：Right circuit has 2 qubit(s), but left circuit has 1; pass allow_extend=True to grow the output.
拼接结果：由于 allow_extend=False，已抛出 CircuitStitchingError
```

该测试证明模块不仅能拼接成功路径，也能识别无法自动拼接的输入。

## 技术价值

量子金融算法通常由多个电路片段组成，例如状态制备、预言机、估值旋转、振幅估计、测量读出等。如果每个算法都手写拼接逻辑，容易出现量子比特对齐错误、线宽不足、经典位错配等问题。

智能拼接模块的价值包括：

1. 显式记录拼接关系：`qubit_map` 和 `clbit_map` 让右侧电路如何接入输出电路可追踪。
2. 支持模板化组合：不同量子金融算子可以把状态制备、预言机 和测量模块作为电路片段组合。
3. 降低映射错误：同线宽自动映射、显式映射和扩展映射都由统一函数处理，减少分散脚本中的重复代码。
4. 支撑自动化测试：测试用 `Statevector` 等价性验证拼接结果与手动 `compose()` 结果一致，证明拼接不是只做字符串或门数量拼接，而是保持量子态语义一致。

## 技术原理补充：电路拼接的线映射语义

量子程序拼接的数学本质是把两个电路酉变换按时间顺序复合。若左侧电路为 $U_L$，右侧电路为 $U_R$，在同一寄存器宽度且默认映射下，拼接结果为

$$
U_{stitched}=U_R U_L.
$$

当右侧电路量子比特需要接入输出电路的不同线位时，显式映射 $\pi$ 定义为

$$
\pi:\{0,\ldots,n_R-1\}\rightarrow \{0,\ldots,n_{out}-1\}.
$$

拼接时每条右侧指令 $G(q_{i_1},\ldots,q_{i_k})$ 被重写为

$$
G(q_{\pi(i_1)},\ldots,q_{\pi(i_k)}).
$$

因此，显式映射不仅改变图中线的位置，也改变控制位与目标位的物理含义。测试中 `qubit_map={0:1,1:0}` 使 CNOT 控制和目标对调到输出线位，正是该映射语义的体现。

## 线宽扩展与错误拦截原理

若右侧电路需要的最大目标索引为 $m$，输出电路所需量子位数为

$$
n_{req}=\max(n_L, m+1).
$$

当 $n_{req}>n_L$ 且 `allow_extend=True` 时，模块新增寄存器以满足线宽；当 `allow_extend=False` 时拒绝拼接。拒绝策略很重要，因为量子线路不能像普通数组一样静默截断：截断会改变 Hilbert 空间维度，从 $2^{n_R}$ 错误变为 $2^{n_L}$，导致状态语义完全不同。

经典位映射遵循同样原则。测量结果的 clbit 位置决定了后处理比特串含义，如果经典位错配，金融结果中资产选择、可行态或风险读出都可能被误解释。

## 与量子金融模板的关系

量子金融算法通常由状态制备 $U_{prep}$、预言机 $U_f$、混合或扩散算子 $U_{mix}$、测量读出 $M$ 构成：

$$
C= M\circ U_{mix}\circ U_f\circ U_{prep}.
$$

智能拼接模块提供统一的寄存器映射和扩展机制，使这些片段可以在软件模板中安全组合，并通过 `diagnostics` 留下可审计的拼接证据。
