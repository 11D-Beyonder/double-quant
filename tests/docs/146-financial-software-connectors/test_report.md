# 146 可视化分析工具能对接不少于6项常用金融软件测试报告

## 测试目标

验证金融编程开发页面中的“数据与软件对接”面板能够以可视化方式展示不少于6项常用金融软件，并支持适配器选择、连接信息查看、字段映射查看、样例数据预览、适配器校验和标准数据格式生成。

## 测试范围

- 金融编程开发页面：`/quantumFinance/financial-programming`。
- 第一步“金融软件对接”面板。
- Wind、同花顺 iFinD、东方财富 Choice、Bloomberg、Refinitiv、Tushare Pro、JoinQuant、Qlib 共8项金融软件适配器。
- “验证适配器”入口。
- “生成标准数据格式”入口。

不在本用例中验证经典金融信息数据格式治理和金融编程源码运行；这两部分分别拆分到147和149功能目录。

## 测试方法

本测试采用浏览器 UI 操作方式，测试人员打开 前端页面后，按测试用例执行页面访问、适配器选择、字段映射查看、样例数据预览、适配器校验和标准数据格式生成等操作。

## 通过标准

- 页面可正常打开并展示“数据与软件对接”面板。
- 左侧目录可见8项金融软件，数量不少于6项。
- 选中任一金融软件后，右侧显示连接方式、认证要素、适配场景、字段映射和样例数据预览。
- 点击“验证适配器”后，页面显示校验通过状态。

## 测试结果分析

浏览器 UI 操作结果表明，页面已把8项常用金融软件整理为统一适配器目录，并通过标准字段映射解决不同数据源字段名称不一致的问题。校验入口提供前端侧字段完整性检查，标准数据格式生成入口作为后续数据格式治理功能的交接点，形成“选择软件、查看映射、预览数据、校验适配”的可视化流程。

## 风险与限制

- 当前校验为前端字段映射和样例数据完整性校验，不直接登录外部金融软件。
- Wind、iFinD、Choice、Bloomberg、Refinitiv 等真实接入需要对应账号、终端环境、授权 token 和后端安全配置。
- 本测试仅证明可视化分析工具具备对接入口、映射模型、样例预览和标准数据交接流程。
