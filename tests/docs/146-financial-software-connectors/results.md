# 146 可视化分析工具能对接不少于6项常用金融软件测试结果

## 功能入口

- 前端访问地址：`https://janusq.zju.edu.cn/quantumFinance/financial-programming`
- 页面名称：金融编程开发
- 测试区域：数据与软件对接 / 金融软件对接
- 覆盖功能点：可视化分析工具能对接不少于6项常用金融软件
- 部署状态：前端页面可访问，金融编程开发页面返回 200

## UI 操作流程

1. 打开金融编程开发页面，确认顶层导航选中“金融编程”，页内三步流程停留在“软件对接”。
2. 在第一步“金融软件对接”中查看左侧金融软件选择器和适配器目录。
3. 确认目录包含 Wind、同花顺 iFinD、东方财富 Choice、Bloomberg、Refinitiv、Tushare Pro、JoinQuant、Qlib 共8项软件。
4. 选择 Bloomberg，查看右侧连接方式、认证要素、适配场景、标准字段映射和样例数据预览。
5. 点击“验证适配器”，确认页面显示“已验证”和校验通过提示。
6. 确认“生成标准数据格式”入口可见，作为软件适配结果向后续数据格式治理功能的交接入口。

## 页面输出

- 金融软件选择器支持8项常用金融软件或金融数据平台，数量满足“不少于6项”要求。
- 每项适配器均展示连接方式、认证要素、适配场景。
- 标准字段映射覆盖证券代码、交易日期、开盘价、最高价、最低价、收盘价、成交量、成交额、复权因子。
- 样例数据预览展示标准化后的行情数据。
- “验证适配器”按钮会执行字段映射和样例数据完整性校验。
- “生成标准数据格式”入口可见，可作为后续147数据格式治理用例的输入来源。


## 验证结论

通过浏览器 UI 操作确认，金融编程开发页面已提供8项金融软件对接入口，超过“不少于6项”的功能要求；适配器连接信息、字段映射、样例数据预览、适配器校验和标准数据格式生成入口均可通过可视化界面查看和操作。
