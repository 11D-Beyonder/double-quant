# 85 量子程序自动修正技术测试（Func-52） 技术报告

## 技术设计

量子程序自动修正模块的实现入口是 `double_quant.algorithm.circuit.repair_quantum_circuit()`，核心对象是 `QuantumProgramRepairer`。调用方传入 Qiskit `QuantumCircuit` 后，模块按执行模式和目标约束生成一个新的修正电路，不直接改写原始电路。

输出对象为 `RepairResult`：

| 字段 | 说明 |
|---|---|
| `circuit` | 修正后的 Qiskit 电路 |
| `diagnostics` | 每一步检测和修正的结构化说明 |
| `applied_fixes` | 实际执行的修正编码，例如 `TRANSPILED_TO_BASIS` |

处理流程如下：

```text
输入 QuantumCircuit
  -> 复制原始电路
  -> 根据执行模式检查测量结构
  -> 根据 basis_gates 检查并执行门集转译
  -> 输出 RepairResult
```

当前功能点覆盖三类自动修正。

### 1. 门集不兼容修正

当目标后端或实验设置只接受指定基础门集时，原始电路中可能存在不被支持的门。例如原始电路只有一个 Hadamard 门：

```text
修正前电路：
   ┌───┐
q: ┤ H ├
   └───┘
修正前摘要：量子比特数=1，经典比特数=0，门操作={'h': 1}
```

调用：

```python
repair_quantum_circuit(
    circuit,
    mode="状态向量",
    basis_gates=["u3"],
    optimization_level=0,
)
```

修正后电路为：

```text
修正后电路：
   ┌─────────────┐
q: ┤ U3(π/2,0,π) ├
   └─────────────┘
修正后摘要：量子比特数=1，经典比特数=0，门操作={'u3': 1}，修正项=['门集转译（TRANSPILED_TO_BASIS）']
```

这说明模块将 `h` 门转译为目标门集允许的 `u3` 门，并通过 `Statevector` 等价性验证转译前后量子态一致。

### 2. 状态向量模式测量修正

状态向量模拟要求电路中不能包含带经典比特的测量指令。原始电路如果已经调用 `measure_all()`，直接构造 `Statevector` 会失败：

```text
修正前电路：
        ┌───┐ ░ ┌─┐
     q: ┤ H ├─░─┤M├
        └───┘ ░ └╥┘
meas: 1/═════════╩═
                 0
修正前摘要：量子比特数=1，经典比特数=1，门操作={'h': 1, 'barrier': 1, 'measure': 1}
```

当 `mode="状态向量"` 时，模块调用 Qiskit 的末尾测量移除能力，只去除最终测量和测量引入的经典寄存器，保留真正的量子门：

```text
修正后电路：
   ┌───┐
q: ┤ H ├
   └───┘
修正后摘要：量子比特数=1，经典比特数=0，门操作={'h': 1}，修正项=['移除末尾测量（STRIPPED_FINAL_MEASUREMENTS）']
```

测试中继续验证修正后概率分布为 `[0.5, 0.5]`，说明修正没有改变 Hadamard 门产生的叠加态。

### 3. 抽样模式测量补全

抽样或 抽样执行需要测量结果。如果原始电路只有量子门，没有经典测量，抽样结果无法产生比特串：

```text
修正前电路：
     ┌───┐
q_0: ┤ H ├──■──
     └───┘┌─┴─┐
q_1: ─────┤ X ├
          └───┘
修正前摘要：量子比特数=2，经典比特数=0，门操作={'h': 1, 'cx': 1}
```

当 `mode="sampling"` 时，模块自动为所有量子比特补充测量：

```text
修正后电路：
        ┌───┐      ░ ┌─┐
   q_0: ┤ H ├──■───░─┤M├───
        └───┘┌─┴─┐ ░ └╥┘┌─┐
   q_1: ─────┤ X ├─░──╫─┤M├
             └───┘ ░  ║ └╥┘
meas: 2/══════════════╩══╩═
                      0  1
修正后摘要：量子比特数=2，经典比特数=2，门操作={'measure': 2, 'h': 1, 'cx': 1, 'barrier': 1}，修正项=['补充抽样测量（ADDED_MEASUREMENTS）']
```

修正后电路保留原有 Bell 态制备结构，并增加 2 个经典测量位。

## 技术价值

量子金融算法通常需要在不同执行方式之间切换，例如状态向量验证、抽样执行、振幅估计或后端转译。自动修正模块把这些执行前处理从实验脚本中抽出来，形成统一的电路预处理能力。

具体价值包括：

1. 提高实验可复现性：每次修正都会记录在 `applied_fixes` 和 `diagnostics` 中，能够说明电路从什么状态变成什么状态。
2. 降低运行失败率：常见错误如“状态向量电路含测量”“抽样电路无测量”“电路门集不匹配”可以在执行前处理。
3. 保持电路语义可验证：测试用 `Statevector` 等价性和概率分布验证修正前后的量子语义关系，不只检查代码是否运行成功。
4. 适合作为算子库入口：后续 HHL、QAOA、量子 Shapley 等量子金融算子都可以先经过该模块进行执行前电路规范化。

## 技术原理补充：自动修正的语义保持条件

量子程序自动修正必须满足两个条件：一是修正后电路满足目标执行模式约束，二是尽可能保持原量子语义。对纯量子门部分，若原电路酉矩阵为 $U$，门集转译后电路为 $\tilde U$，理想语义保持条件为

$$
\tilde U=e^{i\phi}U,
$$

其中全局相位 $e^{i\phi}$ 不影响测量概率。测试中使用状态向量等价性或概率分布验证，实质上是在检查

$$
|\tilde U|0\rangle|^2=|U|0\rangle|^2.
$$

状态向量模式移除末尾测量的原理是：末尾测量属于非酉读出操作，会把纯态坍缩为经典结果，不适合 `Statevector` 前缀演化。若测量只位于电路末端，则移除它不会改变测量前的量子态 $|\psi\rangle$；后续仍可由 $|\alpha_k|^2$ 计算概率。若测量位于电路中间，则后续门可能依赖坍缩结果，模块会拒绝修正，避免错误地把非酉过程当作酉演化。

抽样模式补充测量则是在电路末尾添加

$$
M: |\psi\rangle\mapsto \{k\sim |\alpha_k|^2\},
$$

使后端能够输出经典比特串。该操作改变的是读出层，不改变测量前的制备电路。

## 门集转译与后端约束

真实量子后端通常只支持有限基础门集 $\mathcal{G}$。自动修正通过 Qiskit pass manager 把原门序列分解到 $\mathcal{G}$ 上：

$$
U_g\approx G_s\cdots G_2G_1,\quad G_i\in\mathcal{G}.
$$

当测试把 `h` 转译为 `u3` 时，使用的是等价关系

$$
H=U3\left(\frac{\pi}{2},0,\pi\right)
$$

（忽略全局相位）。因此修正报告中的 `TRANSPILED_TO_BASIS` 代表电路已经从算法门集合适配到目标执行门集合，而不是简单重命名。
