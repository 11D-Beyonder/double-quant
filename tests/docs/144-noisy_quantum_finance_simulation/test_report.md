# 144 仿真工具支持含噪量子金融计算模拟 func-144 测试报告

## 测试目标

验证仿真工具能够加载不同噪声模型，并在 5 组噪声配置下执行含噪量子金融计算模拟。

## 测试范围

退极化噪声配置、含噪仿真后端、shots 采样输出、不同单比特和双比特门错误率组合。

## 测试方法

执行独立测试脚本 `tests/scripts/144-noisy_quantum_finance_simulation.py`，检查程序是否输出 PASS，并核对 5 组噪声模拟是否均输出后端、采样次数、单比特错误率、双比特错误率和非零测量态数量。

## 通过标准

脚本退出码为 0，输出包含 `144` 和 `PASS`；输出包含 5 组噪声配置；每组采样次数为 256；每组后端均为 `noisy_tensor_network`；每组 counts 总和均等于 shots。

## 测试结果分析

- 低噪声、中等噪声和高噪声配置用于验证噪声强度逐步增加时的模拟稳定性。
- 单比特门主导噪声用于验证单比特退极化错误率较高时的采样输出。
- 双比特门主导噪声用于验证双比特门退极化错误率较高时的采样输出。

## 实际验证记录

测试命令：`.venv/bin/python tests/scripts/144-noisy_quantum_finance_simulation.py`。

## 风险与限制

本项为本地 CPU 环境下的功能验收测试；不同 Qiskit Aer 版本、随机种子或后端实现可能导致非零测量态数量略有变化，但不影响 5 组噪声配置的功能验收。

## 测试结论

通过。仿真工具支持在 5 组不同噪声配置下执行含噪量子金融计算模拟，并输出每组噪声对应的采样结果。
