# 147 可视化分析工具能对接经典金融信息数据格式测试报告

## 测试目标

验证金融编程开发页面中的“经典金融信息数据格式”面板能够以可视化方式展示常见金融数据文件和目录格式，并支持格式选择、读取方式说明、质量规则查看、标准字段映射、样例数据预览和数据格式校验。

## 测试范围

- 金融编程开发页面：`/quantumFinance/financial-programming`。
- 第二步“数据格式治理”面板。
- CSV、Excel、JSON、Parquet、Qlib、Arrow / Feather、HDF5 共7类经典金融信息数据格式。
- “验证数据格式”入口。

不在本用例中验证金融软件适配器目录和金融编程源码运行；这两部分分别拆分到146和149功能目录。

## 测试方法

本测试采用浏览器 UI 操作方式，不使用终端脚本作为测试证据。测试人员打开 A100 前端页面后，进入第二步“数据格式治理”，检查格式目录、格式说明、质量规则、字段映射和样例数据预览，并点击“验证数据格式”确认校验入口可用。截图直接来自浏览器 UI，作为测试步骤证据插入 Word 测试用例。

## 通过标准

- 页面可正常打开并进入“数据格式治理”步骤。
- 左侧格式目录可见 CSV、Excel、JSON、Parquet、Qlib、Arrow / Feather、HDF5 共7类格式。
- 选中任一格式后，右侧显示文件形态、读取方式、适配场景和质量规则。
- 标准字段映射与样例数据预览可见。
- 点击“验证数据格式”后，页面显示校验通过状态。

## 测试结果分析

浏览器 UI 操作结果表明，页面已把经典金融信息数据格式整理为统一格式目录，并使用标准字段映射把不同格式中的行情字段归一化。质量规则覆盖字段完整性、交易日期排序、价格数值类型和空值检查等关键数据治理要求，可以为后续金融编程源码生成提供结构化输入。

## 风险与限制

- 当前 UI 截图以页面内置样例数据为准，未在本用例中上传真实本地文件。
- Qlib、Arrow / Feather、HDF5 等目录型或二进制格式在浏览器侧主要展示读取方式和标准化结果，真实批量读取应由后端或运行环境处理。
- 本测试仅验证经典金融信息数据格式的可视化对接、映射和校验能力。
