# 147 可视化分析工具能对接经典金融信息数据格式测试结果

## 功能入口

- 前端访问地址：`https://janusq.zju.edu.cn/quantumFinance/financial-programming`
- 页面名称：金融编程开发
- 测试区域：数据与软件对接 / 经典金融信息数据格式
- 覆盖功能点：可视化分析工具能对接经典金融信息数据格式

## UI 操作流程

1. 打开金融编程开发页面，在页内步骤导航中进入“数据格式”。
2. 在左侧“格式类型”选择器和格式目录中查看全部数据格式。
3. 确认 CSV、Excel、JSON、Parquet、Qlib、Arrow / Feather、HDF5 共7类经典金融信息数据格式可见。
4. 选择 CSV，查看右侧文件形态、读取方式、适配场景、质量规则、标准字段映射和样例数据预览。
5. 点击“验证数据格式”，确认页面显示校验通过状态。

## 页面输出

- 格式目录覆盖7类经典金融信息数据格式。
- 每类格式均展示文件形态、读取方式、适配场景和质量规则。
- 标准字段映射覆盖证券代码、交易日期、开盘价、最高价、最低价、收盘价、成交量、成交额、复权因子。
- 样例数据预览展示标准化后的行情数据。
- “验证数据格式”按钮会检查字段映射、必填字段、样例数据和数值类型。


## 验证结论

通过浏览器 UI 操作确认，金融编程开发页面已提供 CSV、Excel、JSON、Parquet、Qlib、Arrow / Feather、HDF5 等7类经典金融信息数据格式对接入口；格式说明、质量规则、标准字段映射、样例数据预览和格式校验入口均可视化呈现。
