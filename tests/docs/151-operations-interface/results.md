# 151 面向运维人员的编程开发接口测试结果

## 功能入口

- 管理员端入口：`/quantumFinance/admin/ops-interface`
- 验证地址：`http://janusq.zju.edu.cn/quantumFinance/admin/ops-interface`
- 菜单名称：运维接口测试
- 访问角色：管理员
- 默认测试账号：`admin6 / 123456`

## 页面输出

运维接口测试页面包含两个工作区：

1. 接口巡检：展示股票数据状态、股票池分页、数据导入记录、Redis 兼容性检查、Python 算法环境、QASM 语法校验、QASM 运行、量子电路配置、期权定价冒烟、任务统计、任务分页、管理员用户列表、证券搜索等运维接口。
2. 请求调试：支持选择预置接口，自动加载可运行的查询参数和请求体 JSON；也支持从巡检表单行点击“调试”跳转并载入对应样例。
