# 149 面向金融人员的编程开发接口测试报告

## 测试目标

验证金融编程开发页面的第三步“金融编程执行”是否提供面向金融人员的编程开发接口，包括源码编辑区、算法模板、参数设置、运行入口和可视化运行结果。

## 测试范围

- 金融编程开发页面：`/quantumFinance/financial-programming`。
- 第三步“金融编程执行”面板。
- 金融编程源码编辑区。
- 算法选择、模板加载、问题类型、shots 参数和运行按钮。
- 量子线路、运行结果、金融结果和概率分布图。

不在本用例中重复验证金融软件适配器目录和经典金融信息数据格式目录；这两部分分别拆分到146和147功能目录。

## 测试方法

本测试采用浏览器 UI 操作方式，不使用终端脚本作为测试证据。测试人员通过前置页面操作生成金融编程源码后，进入第三步“金融编程执行”，查看源码编辑区和工具栏，点击“运行”，等待可视化区域显示量子线路、运行结果、金融结果和概率分布图，并保存关键步骤截图。

## 通过标准

- 第三步“金融编程执行”可以打开并显示已载入源码状态。
- 源码编辑区显示标准化行情数据和金融算法模板。
- 工具栏提供算法选择、模板加载、问题类型、shots 参数和运行按钮。
- 点击“运行”后，页面显示量子线路。
- 页面显示测量结果分布或概率分布图。

## 测试结果分析

浏览器 UI 操作结果表明，金融编程执行面板已具备面向金融人员的开发接口形态。用户可以从前置数据步骤生成源码，也可以在第三步查看和调整源码、选择算法模板、配置运行参数并启动计算。运行完成后，页面在同一工作区展示量子线路和金融结果，避免用户在多个系统之间切换。

## 风险与限制

- 本测试以页面生成的样例源码为准，没有覆盖所有金融算法模板。
- 运行结果依赖后端量子金融接口和当前部署环境，若后端不可用，第三步可能只能验证源码编辑和运行入口。
- 本测试仅验证面向金融人员的 UI 编程接口与可视化运行结果，不评价具体金融算法收益或精度。
