# 149 面向金融人员的编程开发接口测试结果

## 功能入口

- 前端访问地址：`https://janusq.zju.edu.cn/quantumFinance/financial-programming`
- 页面名称：金融编程开发
- 测试区域：金融编程执行
- 覆盖功能点：面向金融人员的编程开发接口

## UI 操作流程

1. 打开金融编程开发页面，通过前置数据与格式步骤生成金融编程源码，进入第三步“金融编程执行”。
2. 查看左侧金融编程源码编辑区，确认标准化行情数据和金融算法模板已载入。
3. 查看顶部算法选择、模板加载、问题类型、shots 参数和“运行”按钮。
4. 点击“运行”，等待页面展示量子线路、运行结果、金融结果和概率分布图。
5. 查看运行结果区域中的问题类型、金融领域、运行时间、算法名称、估值对象和估值结果。

## 页面输出

- 源码编辑区显示面向金融人员的金融编程源码，包含标准化行情数据、收益率计算和金融算法调用。
- 工具栏提供算法选择、模板加载、问题类型选择、shots 参数输入和运行入口。
- 运行后展示量子线路、运行结果、金融结果和测量结果分布。
- 运行结果以可视化方式反馈算法执行状态和金融结果，便于金融人员在页面内完成源码查看、运行和结果分析。


## 验证结论

通过浏览器 UI 操作确认，金融编程开发页面已提供面向金融人员的源码编辑、算法模板、参数设置、运行入口和可视化结果查看能力，能够支撑金融人员在同一界面完成从源码检查到运行结果分析的开发流程。
